 -->Brief Description of the Portfolio

This portfolio website is a personal full-page web project designed to showcase my profile, skills, projects, and contact information. It presents a clean, modern layout with interactive elements and smooth scrolling, allowing visitors to easily navigate through different sections of the page.

----------------------------------------

 -->Page Overview

* Home Section:
  Introduces the portfolio with a background image, logo, navigation menu, and a short introduction.

* About Section:
  Provides personal information, profile image, skills, and experience using tab-based content.

* Projects Section:
  Displays featured projects in interactive cards with hover effects and overlay layers.

* Contact Section:
  Contains contact details, social media links, and a functional contact form.

* Footer:
  Displays copyright information and completes the page layout.

----------------

-->Key HTML & CSS Features Implemented

* Semantic HTML elements (`header`, `nav`, `section`, `footer`)
* CSS Flexbox for layout alignment and structure
* Pseudo-elements (`::after`) for navigation hover effects
* Smooth scrolling using `scroll-behavior`
* Hover animations and transitions for interactive UI
* Background images with `background-size: cover`
* Custom buttons, forms, and overlay layers
* Font and color customization for consistent design

-------------------------------------------

 -->Responsive Design Approach

The website follows a mobile-first responsive design strategy using CSS media queries.
Layouts adapt seamlessly across:

* Mobile devices (320px and above):
  Sections stack vertically, images resize, and navigation adjusts for smaller screens.

* Tablets (768px and above):
  Flex layouts rearrange content for balanced spacing and readability.

* Desktops (1024px and above):
  Full-width layout with enhanced spacing, larger typography, and interactive hover effects.

This ensures optimal usability and visual consistency across all screen sizes.
